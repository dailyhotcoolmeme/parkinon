```

💊 약 복용을 잊지 않게 도와드려요
약 드실 시간이 되면 알려드려요. 드셨으면 탭 한 번으로 기록 끝.
약을 드시지 않으시면 가족에게도 알림이 가요.

😊 몸 상태를 꾸준히 기록해요
약 드신 후 몸 상태가 어떤지 간단하게 남겨두세요.
시간이 지나면서 패턴이 보이고, 다음 진료 때 참고할 수 있어요.

👨‍👩‍👧 가족이 함께 볼 수 있어요
배우자, 자녀가 함께 연동하면 멀리 있어도 약을 잘 드셨는지 확인할 수 있어요.
서로 일일이 전화하지 않아도 돼요.

🏃 운동도 함께 기록해요
파킨슨 관리에 중요한 운동을 기록하고, 전문 운동 영상도 볼 수 있어요.
몸 상태가 좋을 때 운동을 추천해드려요.

📰 파킨슨 정보와 나눔
최신 파킨슨 관련 정보와 같은 상황을 겪는 분들과 이야기를 나눌 수 있어요.

─────────────────────────────
주요 기능
─────────────────────────────
✔ 약 복용 알림 (시간 설정, 재알림, 보호자 안내)
✔ 약효 추적 (복용 후 몸 상태 변화 기록)
✔ 몸 상태 / 기분 / 수면 / 변비 기록
✔ 영상 기록 (몸 상태를 영상으로 남기기)
✔ 운동 기록 및 운동 영상 제공
✔ 환자-보호자 가족 연동
✔ 처방전 사진으로 약 등록 (OCR)
✔ 기록 보기 (주간/월간/3개월 트렌드)
✔ 파킨슨 정보 피드 및 커뮤니티

─────────────────────────────
이런 분들께 추천해요
─────────────────────────────
• 파킨슨 진단을 받으신 분
• 파킨슨 환자를 돌보는 가족
• 약 복용 시간을 자주 잊으시는 분
• 몸 상태 변화를 꾸준히 기록하고 싶으신 분
• 진료 때 의사 선생님께 보여드릴 기록이 필요하신 분

─────────────────────────────
주의 사항
```

## 10. 권한 목록 및 사유

```
android.permission.CAMERA
→ 처방전 사진 촬영, 몸 상태 영상 기록

android.permission.READ_MEDIA_VIDEO
android.permission.READ_MEDIA_IMAGES
→ 갤러리에서 영상/사진 선택

android.permission.POST_NOTIFICATIONS
→ 약 복용 알림, 약효 추적 알림

android.permission.INTERNET
→ 서버 통신, 유튜브 영상 재생

android.permission.RECEIVE_BOOT_COMPLETED
→ 기기 재시작 후 알림 복원
```

## 13. EAS Build 명령어

```bash
# 프로덕션 AAB 빌드 (플레이스토어 업로드용)
eas build --platform android --profile production

# 플레이스토어 자동 제출
eas submit --platform android
```

### eas.json 설정
```json
{
  "build": {
    "production": {
      "android": {
        "buildType": "app-bundle",
        "gradleCommand": ":app:bundleRelease"
      }
    }
  },
  "submit": {
    "production": {
      "android": {
        "serviceAccountKeyPath": "./google-service-account.json",
        "track": "production"
      }
    }
  }
}
```

## 15. 출시 단계 및 구글 필수 요건

### ⚠️ 중요: 구글 플레이 출시 테스트 요건

### 개인 계정 vs 조직 계정

| 구분 | 비공개 테스트 |
|------|------|
| 개인 계정 (2023년 11월 이후 생성) | 신규 앱마다 필요 (12명, 14일) |
| 조직 계정 (사업자) | 테스트 없이 바로 출시 가능 |

→ **아워마인 사업자 있으면 조직 계정 권장**

### 필수 조건 요약

| 항목 | 내용 |
|------|------|
| Android 타겟 | Android 15 (API 레벨 35) 이상 |
| 개인정보처리방침 | 웹 URL 등록 필수 |
| 콘텐츠 등급 설문 | Play Console에서 완료 필수 |
| 앱 서명 키 | Play 앱 서명 설정 필수 |

### 단계별 흐름 (개인 계정 기준)

```
1단계: 내부 테스트 (선택, 권장)
   → 개발팀 + 지인 (최대 100명)
   → Play Console에 등록 즉시 배포

2단계: 비공개 테스트 (계정당 1회)
   → 12명 이상 테스터 (Gmail 계정 필요)
   → 14일 이상 유지
   → 테스터들이 실제로 앱 다운로드해야 함
   → 완료 후 프로덕션 액세스 권한 신청 가능

3단계: 공개 출시 (Production)
   → 이후 추가 앱도 신규 앱이면 동일하게 비공개 테스트 필요
   → 첫 제출 후 검토까지 최소 1주일 여유 필요
```

### 조직 계정 등록 방법 (권장)

```
준비물:
- D-U-N-S 번호 (무료 신청, 1~2주 소요)
- 사업자등록증
- 영문 사업자등록증명
- 통신판매업 신고번호
- 회사 웹사이트 URL
- $25 등록비 (1회)
```
