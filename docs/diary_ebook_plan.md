# 파킨온 일기 → ebook 발행 방안 (방향 합의, 작업 보류)

상태: **방향 합의 완료 / 구현 보류** (2026-06-13)
관련: `docs/diary_feature_spec.md`, 일기 기능(`src/screens/diary/DiaryScreen.tsx`, `src/hooks/useDiary.ts`)

## 핵심 난제
책(특히 PDF·인쇄)은 정적이라 **영상·음성을 직접 재생할 수 없음**. → 책 형태에 따라 AV(오디오·비디오) 표현 방식이 갈린다.

## 합의된 로드맵
1차 **웹 디지털북** → 2차 **PDF 전자책** → 3차 **실물 사진책(POD)**. (앱 내 "책처럼 보기"는 1차의 부분집합으로 자연 포함)

### 1차: 웹 디지털북 (공유 링크 / 플립북) — 채택
- 기간(월/분기/커스텀) 선택 → 웹페이지(플립북)로 발행 → **링크로 가족 공유·선물**.
- **영상·음성 그대로 재생** (정적 포맷이 아닌 유일한 디지털 방법).
- 인프라: 이미 보유한 **Cloudflare Pages + R2** 활용(추가 비용 적음). 배포 토큰 `~/.config/parkinon/cf-deploy-token` (see [[reference_parkinon_web_deploy]]).
- 수익화: 프리미엄 발행 / 구독.

### 2차: PDF 전자책 (다운로드·메일)
- 빈티지 일기 디자인 그대로 텍스트+사진 고정 레이아웃. **영상·음성은 QR코드/링크**(스캔→호스팅 재생 페이지).
- 수익화: 유료 내보내기.

### 3차: 실물 사진책 (주문제작 POD)
- 인쇄 키프세이크 — 환자·가족 기념물, **수익화 객단가 최고**. AV는 페이지 QR코드. 인쇄 제휴·배송 필요.

## 영상·음성 표시 기법 (정적 포맷용)
1. **QR코드 → R2 호스팅 재생 페이지**(서명 URL). 스캔하면 폰에서 재생.
2. **대표 프레임(영상 썸네일)+길이+캡션** 인쇄.
3. **음성=파형 그림+QR**, 또는 즉시 녹음분의 **STT 받아쓰기 텍스트를 본문 병기**(음성을 글로도 남김).

## 보유 데이터(발행 소스)
- `diary_entries`(text, photo_urls[], video_media_id→media_logs, audio_url) + 자동 기록(약/약효/운동) 일자별. 환자·보호자 공동 작성 → 시간순 책 구성에 적합.
