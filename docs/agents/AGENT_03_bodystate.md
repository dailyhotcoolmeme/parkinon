## 필수 지킬사항

1. DESIGN_SYSTEM.md 기준 100% 준수. 버튼 최소 56dp, 글씨 최소 18sp.
2. 팝업은 반드시 화면당 질문 하나. 절대 한 화면에 여러 질문 넣지 말 것.
3. 수면 질문은 하루 첫 번째 기록 시에만 표시.
4. 변비 질문은 하루 마지막 기록 시에만 표시.
5. triggered_by 필드 반드시 저장. 알림='notification', 수시='manual'.
6. 몸상태/기분 4~5점 입력 시 반드시 운동 팝업 트리거.
7. 영상 선택 즉시 duration 체크. 2분 초과 시 바로 알림.
8. 영상 미리보기 제공 후 저장. 저장 전 다시 찍기 옵션 필수.
9. 리스트에 영상 첨부된 기록은 🎬 아이콘 표시.
10. 이전 기록 점수를 팝업에 항상 표시.
11. 보호자 - 따로 거주: 버튼 회색 비활성화 + 안내 문구 필수.
