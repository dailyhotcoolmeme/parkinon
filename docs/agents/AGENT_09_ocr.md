## 커스텀 훅
- usePrescriptionOCR - 처방전 사진 → Claude API 호출 → 결과 파싱

## 유틸 함수
- maskPersonalInfo - 처방전 개인정보 마스킹
- checkDuplicate - 약 중복 체크

---

## 필수 지킬사항

1. DESIGN_SYSTEM.md 기준 100% 준수. 버튼 최소 56dp, 글씨 최소 18sp.
2. 처방전 사진 분석 전 반드시 개인정보 마스킹 처리.
3. 원본 사진은 분석 완료 즉시 삭제. 절대 저장하지 말 것.
4. 분석 중 로딩 화면 반드시 표시.
5. 분석 실패 시 안내 문구 + 다시 찍기 / 직접 입력 선택지 제공.
6. 약 확인 화면에서 반드시 전체 교체 / 추가 선택지 제공.
7. 추가 선택 시 중복 약 체크 후 약 관리 화면에서 경고 표시.
8. 분석 결과는 사용자가 수정 가능해야 함. 수정할게요 버튼 필수.
