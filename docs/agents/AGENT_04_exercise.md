## 필수 지킬사항

1. DESIGN_SYSTEM.md 기준 100% 준수. 버튼 최소 56dp, 글씨 최소 18sp.
2. 🏃 운동 기록하기 버튼은 화면 중앙 크게. 절대 작게 만들지 말 것.
3. 운동 영상 보기는 보조 링크 느낌으로 작게 표시.
4. 기본 4가지 운동은 항상 2x2 그리드로 표시.
5. 기타 운동은 + 버튼 탭 시 표시.
6. 운동 시간 선택지: 10분/20분/30분/40분/50분/60분/90분/120분/직접입력 고정.
7. 저장 후 운동 탭 메인으로 바로 복귀.
8. 영상 탭 시 인앱 유튜브 플레이어로 재생. 유튜브 앱으로 나가지 않게 할 것.
9. 보호자 - 따로 거주: 버튼 회색 비활성화 + 안내 문구 필수.
10. 운동 영상 ID는 PENDING 상태. 크롤링 완료 전까지 빈 목록 표시.
