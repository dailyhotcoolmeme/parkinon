## 주요 기능

- 약 복용 알림 (Expo Notifications)
- 약 복용 재알림 (+10분 미복용 시)
- 보호자 알림 (+20분 미복용 시)
- 약효 추적 알림 (복용 후 30분, 2시간)
- 운동 알림 (사용자 설정 시간)
- 운동 팝업 트리거 (몸상태 4~5점 입력 시)
- 알림 탭 시 해당 화면으로 딥링크

---

## 커스텀 훅

- `useNotification` - Expo 알림 권한/등록/처리
- `useMedAlarm` - 약 복용 알림 스케줄링

## 알림 흐름

```
복용 예정 시간 → 미입력 → 첫 알림
  "(파킨온) 아침 약 복용 시간이에요."
→ +10분 미입력 → 재알림
  "(파킨온) 아직 아침 약을 드시지 않으셨어요."
→ +10분 미입력 → 환자 알림 + 보호자 알림
  환자: "(파킨온) 아직 아침 약을 드시지 않으셨어요. 보호자가 걱정하고 있어요."
  보호자: "(파킨온) OOO님께서 아직 아침 약을 드시지 않으셨어요."
```

---

## 알림 문구 목록

```
약 복용 알림:      "(파킨온) {시간대} 약 복용 시간이에요."
약 재알림:         "(파킨온) 아직 {시간대} 약을 드시지 않으셨어요."
보호자 미복용 알림: "(파킨온) {환자명}님께서 아직 {시간대} 약을 드시지 않으셨어요."
약효 추적 알림:    "(파킨온) {시간대}약 드신 후 {N}분이 지났어요. 몸 상태를 기록해보세요."
운동 알림:         "(파킨온) 오늘 운동할 시간이에요."
```

## 필수 지킬사항

1. 알림 권한은 온보딩 완료 직후 요청. 강요하지 말고 안내 후 요청.
2. 약 복용 알림은 기본 ON. 사용자가 끄기 전까지 발송.
3. 운동 알림은 기본 OFF. 사용자가 시간 설정 시에만 ON.
4. 약효 추적 알림은 기본 ON. 복용 후 30분, 2시간 고정.
5. 알림 탭 시 해당 화면으로 바로 이동. (약 복용 알림 → 약복용 탭, 약효 추적 알림 → 몸상태 탭)
6. 알림 통해 몸상태 입력 시 triggered_by = 'notification' 반드시 저장.
7. 보호자 알림은 설정에서 항목별 ON/OFF 가능. 기본 모두 ON.
8. 약 복용 완료 후 해당 시간대 알림 자동 취소.
9. 알림 문구는 쉬운 말, 존댓말 유지.
10. Supabase Realtime으로 보호자 알림 실시간 처리.

## 오케스트레이터 보고 형식

작업 완료 시 반드시 아래 형식으로 오케스트레이터(AGENT_00)에게 보고한다.

```
[완료 보고]
에이전트: AGENT_XX [에이전트명]
작업 내용: [구현한 내용 요약]
완료 항목:
  ✅ [완료 항목]
미완료 항목:
  ❌ [미완료 항목] (사유: [사유])
특이사항: [있으면 기재, 없으면 없음]
```

검수 에이전트로부터 재작업 지시 받을 경우:
1. 지시 내용 확인
2. 수정 작업 완료
3. 오케스트레이터에게 재보고
