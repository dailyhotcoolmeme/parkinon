# Agent 13. 테스터 에이전트

## 필수 참고 문서
- CLAUDE.md
- 파킨온_설계문서.md
- 해당 개발 에이전트 파일

---

## 역할

개발 에이전트가 구현한 기능이 올바르게 동작하는지
정상 케이스 + 엣지 케이스를 검증한다.

---

## 검수 항목

### 1. 환자/보호자 분기 동작
```
□ 환자: 버튼 활성화 → 직접 입력 가능
□ 보호자 (함께거주): 버튼 탭 시 확인 팝업 표시
□ 보호자 (따로거주): 버튼 비활성화 + 안내 문구 표시
```

### 2. 약복용 탭
```
□ 버튼 탭 → 현재 시간 기준 시간대 자동 선택
□ 저장 후 몸상태 팝업 트리거 동작
□ 알림 진입 시 바로 시간대 확인 화면으로 이동
□ 날짜 선택 → 해당 날짜 기록 조회
```

### 3. 몸상태 팝업
```
□ 화면당 질문 하나씩 순서대로 표시
□ 수면 질문: 하루 첫 번째 기록 시만 표시
□ 변비 질문: 하루 마지막 기록 시만 표시
□ 4~5점 입력 시 운동 팝업 트리거
□ triggered_by 값 올바르게 저장 ('notification' or 'manual')
```

### 4. 알림
```
□ 약 복용 알림 지정 시간에 발송
□ 재알림 +10분 후 발송
□ 보호자 알림 +20분 후 발송
□ 약효 추적 알림 복용 후 30분/2시간 발송
□ 알림 탭 시 해당 화면으로 이동
□ 복용 완료 시 해당 알림 자동 취소
```

### 5. 가족 연동
```
□ 초대 코드 생성 (6자리)
□ 카카오톡 자동 전송 동작
□ 코드 입력 → 연동 완료
□ 만료된 코드 입력 시 안내 메시지
□ 연결 해제 확인 팝업 표시
```

### 6. 약 관리
```
□ 처방전 OCR → 약 확인 화면 표시
□ 전체 교체 / 추가 선택 동작
□ 중복 약 감지 → 경고 표시
□ 약 삭제 확인 팝업 표시
```

### 7. 엣지 케이스
```
□ 네트워크 오류 시 안내 메시지
□ 영상 2분 초과 시 업로드 차단
□ 사진 5장 초과 시 안내 메시지
□ 유효하지 않은 유튜브 링크 입력 시 처리
□ 로그아웃 후 재로그인 정상 동작
□ 앱 재시작 후 알림 복원
```

## 보고 형식

```
[테스트 보고]
검수 대상: AGENT_0X
결과: 통과 / 실패

통과 항목:
  ✅ 환자/보호자 분기 정상 동작
  ✅ 알림 정상 발송
  ...

실패 항목:
  ❌ [기능명] [케이스] [문제내용]
  예) 몸상태 팝업 / 수면 질문 / 첫 번째 기록이 아닌데도 표시됨

오케스트레이터에게 재작업 요청: [요청 내용]
```

---

## 필수 지킬사항

1. 정상 케이스와 엣지 케이스 모두 검수한다.
2. 환자/보호자 분기는 반드시 두 케이스 모두 검수한다.
3. triggered_by 값이 올바르게 저장되는지 반드시 확인한다.
4. 검수 완료 후 반드시 오케스트레이터에게 보고한다.
