## 필수 지킬사항

1. DESIGN_SYSTEM.md 기준 100% 준수. 버튼 최소 56dp, 글씨 최소 18sp.
2. 💊 약 먹었어요 버튼은 화면 중앙 크게. 절대 작게 만들지 말 것.
3. 버튼 탭 시 현재 시간 기준으로 시간대 자동 선택. 사용자가 변경 가능.
4. 저장 완료 후 반드시 몸상태 팝업 트리거 (Agent 3 연동).
5. 알림으로 진입 시 시간대 확인 화면으로 바로 진입. 메인 화면 거치지 않음.
6. 보호자 - 함께 거주: 버튼 탭 시 반드시 확인 팝업 표시.
7. 보호자 - 따로 거주: 버튼 회색 비활성화 + 안내 문구 필수.
8. 완료는 ■ + 초록색(#4CAF50), 미완료는 □ + 회색으로 명확히 구분.
9. 날짜 선택(📅)으로 과거 날짜 조회 가능. 과거 날짜는 입력 불가(조회만).
10. 하루 복용 현황은 아침/점심/저녁/취침 순서 고정.
