## 필수 지킬사항

1. DESIGN_SYSTEM.md 기준 100% 준수. 버튼 최소 56dp, 글씨 최소 18sp.
2. 크롤링 기사: 📰 뱃지 반드시 표시. 사용자 게시글에는 뱃지 없음.
3. 리스트: 제목+작성자·날짜·조회수 왼쪽, 썸네일 오른쪽, 댓글수 맨 오른쪽.
4. 썸네일 없는 게시글은 썸네일 영역 없이 텍스트만 표시.
5. 글쓰기 화면: 바텀시트 사용 금지. 반드시 별도 화면으로.
6. 글 유형 선택은 글쓰기 화면 최상단. 선택 필수.
7. 사진 최대 5장. 6장 이상 선택 시 안내 문구 표시.
8. 영상은 유튜브 링크 붙여넣기만 허용. 직접 업로드 불가.
9. 유튜브 링크 입력 시 썸네일+제목 자동 미리보기 표시.
10. 댓글에 대댓글 지원. 대댓글은 들여쓰기로 구분.
11. 좋아요: 게시글 하단바 ♡ + 댓글 우측 ♡ 각각 구현.
12. 크롤링 기사 탭 시 원문 링크로 이동.
