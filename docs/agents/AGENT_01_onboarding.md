## 필수 지킬사항

1. DESIGN_SYSTEM.md 기준 100% 준수. 버튼 최소 56dp, 글씨 최소 18sp.
2. 온보딩 슬라이드는 스킵 불가. 반드시 3장 모두 표시.
3. 로그인은 카카오 단독. Google/Apple 버튼 추가하지 말 것.
4. 역할 선택 후 절대 되돌아갈 수 없음. 선택 신중하게 유도.
5. 기본 정보 입력은 화면당 하나씩. 한 화면에 여러 항목 넣지 말 것.
6. 진행 상황 표시 (1/4, 2/4 등) 상단에 반드시 표시.
7. 진단연도, 거주여부 등 선택 항목은 "나중에 할게요" 옵션 제공.
8. 약 등록은 건너뛸 수 있지만 건너뛸 경우 설정에서 등록 안내 문구 표시.
9. 초대 코드 6자리, 24시간 유효. 만료 시 재발급 안내.
10. 온보딩 완료 후 별도 완료 화면 없음. 바로 홈으로 이동.
11. 카카오 닉네임을 이름 필드에 자동 입력. 사용자가 수정 가능.

## 오케스트레이터 보고 형식

작업 완료 시 반드시 아래 형식으로 오케스트레이터(AGENT_00)에게 보고한다.

```
[완료 보고]
에이전트: AGENT_XX [에이전트명]
작업 내용: [구현한 내용 요약]
완료 항목:
  ✅ [완료 항목]
미완료 항목:
  ❌ [미완료 항목] (사유: [사유])
특이사항: [있으면 기재, 없으면 없음]
```

검수 에이전트로부터 재작업 지시 받을 경우:
1. 지시 내용 확인
2. 수정 작업 완료
3. 오케스트레이터에게 재보고
