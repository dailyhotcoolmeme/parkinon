## news_feed 테이블 저장 항목

```
title       기사 제목
url         원문 링크
thumbnail   og:image URL
source      출처 사이트명
published_at 발행일
created_at  크롤링일
```

---

## 필수 지킬사항

1. 크롤링 기사는 news_feed 테이블에 저장. posts 테이블과 혼용하지 말 것.
2. 중복 기사 필터링: URL 기준으로 중복 체크.
3. og:image 없는 기사는 thumbnail = null로 저장. 썸네일 없이 텍스트만 표시.
4. 크롤링 실패 시 에러 로그 저장. 서비스 중단 없이 다음 기사로 진행.
5. 저작권 주의: 기사 본문 저장 금지. 제목/썸네일/링크만 저장.
6. parkinson.co.kr 운동 영상 ID 수집:
   - 기본/1단계/2단계/3단계/종합 페이지 각각 크롤링
   - 유튜브 embed URL에서 영상 ID 추출
   - 완료 후 운동 에이전트(Agent 4)에 전달
7. GitHub Actions secrets에 Supabase 연결 정보 저장. 코드에 하드코딩 금지.
