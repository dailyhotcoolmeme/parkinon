## 필수 지킬사항

1. DESIGN_SYSTEM.md 기준 100% 준수. 버튼 최소 56dp, 글씨 최소 18sp.
2. 메뉴 화면: 상단에 사용자 이름/역할 표시. 프로필 수정 > 링크 포함.
3. 설정 화면: 각 알림 항목 아래 설명 문구 반드시 포함.
4. 약 관리: 중복 약 있을 경우 화면 상단에 ⚠️ 경고 배너 반드시 표시.
5. 약 삭제: 반드시 확인 팝업 표시.
6. 처방전 재등록: 전체 교체 / 추가 선택 화면 반드시 표시.
7. 가족 초대: 카카오톡 버튼만 표시. 코드 숫자 화면에 노출 불필요.
8. 초대 코드 입력하기 위에 반드시 안내 문구 표시.
9. 가족 연결 해제: 반드시 확인 팝업.
10. 회원탈퇴: 반드시 확인 팝업 + 데이터 삭제 안내.
11. 보호자 메뉴에서 약 관리 탭하면 환자 약 관리 화면으로 진입.
12. 삭제/위험 버튼은 반드시 빨간색(#F44336) 텍스트.

## 오케스트레이터 보고 형식

작업 완료 시 반드시 아래 형식으로 오케스트레이터(AGENT_00)에게 보고한다.

```
[완료 보고]
에이전트: AGENT_XX [에이전트명]
작업 내용: [구현한 내용 요약]
완료 항목:
  ✅ [완료 항목]
미완료 항목:
  ❌ [미완료 항목] (사유: [사유])
특이사항: [있으면 기재, 없으면 없음]
```

검수 에이전트로부터 재작업 지시 받을 경우:
1. 지시 내용 확인
2. 수정 작업 완료
3. 오케스트레이터에게 재보고
