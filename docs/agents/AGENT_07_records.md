## 필수 지킬사항

1. DESIGN_SYSTEM.md 기준 100% 준수. 버튼 최소 56dp, 글씨 최소 18sp.
2. parkinon_records_v6.jsx를 반드시 참고하여 UI 구현.
3. 메인 화면: 이번 주/이번 달/최근 3개월 탭. 탭 전환 시 해당 기간 요약 표시.
4. 각 항목 옆에 지난주/지난달/지난 3개월 글자 반드시 표시. 숫자만 표시하지 말 것.
5. 몸상태/기분 메인: 시간대별(복용직후/30분후/2시간후) 카드로 구분 표시.
6. 약효 패턴: triggered_by = 'notification' 기록만 반영. 수시 입력 제외.
7. 트렌드 그래프: 이전/다음 버튼으로 과거 데이터 계속 조회 가능.
8. 이번 주 탭 → 주별. 이번 달 탭 → 월별. 최근 3개월 탭 → 3개월별.
9. 글씨 크기 60대 이상 기준. 굳이 한 화면에 다 안 나와도 됨 → 스크롤.
10. 상승 ↑ 초록, 하락 ↓ 빨강, 유지 → 회색으로 명확히 구분.
11. 현재 기간 막대는 진하게, 과거는 연하게 표시.
