무엇이 바뀌나 (오너 피드백 반영)

  • 정리카드 하나에 큰 버튼 3개 쌓아서 정신없던 걸 → 이름·날짜 + [들어보기](주황 강조) + [수정][삭제] 한 줄로 깔끔하게. 여백 넉넉히.
  • 추가수정(이름 변경) 기능 — 탭하면 바텀시트로 이름 바꿔 저장. (지금은 삭제만 있었음)
  • 명칭"새 알림음 녹음" → "새 알림음 등록"
  • 테스트"실제 알림으로 들어보기"는 보조(점선 회색)로 내려서 덜 튀게. ※ 오너 결정: 여기 남길까요, 아니면 빼고 알림 관리(소리 고르는 곳)로 옮길까요? (테스트는 "알림에 적용할 때" 더 어울려서요)
  • 제목 "알림음 관리" 통일, 60대용 큰 글씨(이름 21·버튼 17~19)·버튼 54dp+ 유지.
