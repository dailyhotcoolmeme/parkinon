무엇이 바뀌나

  • 묶음 1🔔 약 알림 — 켤까요 토글 + 알림 시간(바꾸기) + 알림 소리 = 약 알림 관련은 전부 파란 박스 한 곳. 전 맨 밑에 떠있던 "시간 바꾸기"를 여기로 올림(오너 요청).
  • 묶음 2💊 몸 상태 여쭤보기 — 켤까요 토글 + 언제(체크줄+직접추가) + 여쭤볼 때 소리 = 초록 박스 한 곳.
  • 두 박스를 색·여백으로 확실히 분리 → "약 알림"과 "몸 상태 여쭤보기"가 다른 거라는 게 눈에 바로 들어옴(섞임 해소).
  • 각 박스 켜고 끄는 토글을 박스 제목 줄에 둬서, 끄면 그 박스 안 내용이 접혀 더 단순해짐.
  • 접힌(요약) 카드는 그대로 — 펼쳤을 때만 이렇게 두 박스로 보임.
