🗑 이 복용 시각 삭제
화면 2 — [바꾸기] 펼침. 칩 대신 큰 체크줄(56dp) · 소프트 경고(막지 않음) · 직접추가는 보호자 모드만

✅ 두 관점이 합의한 것 (그대로 구현 예정)

  • 알림설정 안에서 복용 시각마다 카드 1장 (전역 1세트 폐기). 카드는 별도화면 아닌 인라인 + 아코디언(1개만 펼침).
  • 카드 첫인상은 결정 1개(약 알림 토글). 몸상태 여쭤보기 세부는 접고 사람말 요약 + [바꾸기].
  • 용어 전면 순화: "추적·직후·세트·복용" 단독 노출 금지 → "약 드시고 나서 몸 상태 여쭤보기", "약 드신 바로 뒤" 등 완결 문장.
  • 소프트 경고(겹침)는 막지 않고 안내만 · 주황 · 행동어 버튼([이대로 둘게요]/[다시 고를게요]).
  • 현재 코드의 아이콘 단독 ✏️/🗑 버튼 → 텍스트 포함으로 시정(규칙 위반 해소).
  • 시간/분 선택은 바텀시트(딤·스와이프 닫기). 전체알림·미복용·운동·보호자 카드는 기존 유지.
  • 저장은 토글/체크 즉시 반영(저장 버튼 없음). 활성 카드는 왼쪽 오렌지 띠로만 표시(체크뱃지 덮기 금지).
