# 알림음 개인화 + 구독 기능 — 설계 사양 (진행 중)

> 파킨온의 핵심 차별점: **자녀(보호자) 목소리로 약 챙김 알림**.
> 결정 사항을 합의 즉시 여기에 반영(메모리에 들고 가지 않음).
> 최초 작성: 2026-05-31. **아직 스토어 출시 전(빌드 테스트 단계)** — 이 기능들은 첫 출시 빌드에 포함 예정.

## 1. 확정된 결정 (LOCKED)

### 기능 범위
- **플랫폼**: iOS + Android 둘 다.
- **알림음 종류**: ① 우리가 넣은 **프리셋** 중 선택 + ② 사용자 **직접 녹음** — 둘 다 지원.
- **대상**: **환자 + 보호자 둘 다** 자기 기기에서 받을 알림음·옵션을 각자 설정.
- **녹음 위치**: **앱에서** 녹음(마이크). (적용/설치는 어차피 앱에서만 가능)

### 알림 동작 (사용자 선택형, 언제든 변경)
- 두 가지 축을 **사용자가 직접 선택하고 수시로 변경** (저장된 설정값 → 다음 알림부터 적용, 재빌드 불필요):
  1. **무음 뚫기**: 무음/방해금지 모드에서도 울릴지 ON/OFF
  2. **알림 지속**: 한 번 울림 / 해제할 때까지 계속 울림
- **두 모드 동작 자체는 앱에 미리 구현(네이티브)** 해둬야 함. 그 뒤 선택·변경은 자유.
- **중요 한계 + 사용자 안내 필수**:
  - **약 복용 시간 알림(정해진 시간)** → 기기 예약 알람 → "끝까지 울림" 확실히 동작 ✅
  - **미복용·보호자 알림(서버 푸시, 비정형 시점)** → "끝까지 무한정"은 한계. 무음 뚫고 크게/몇 번 반복은 가능하나 알람시계처럼 무한은 아님.
  - → 설정 화면에 쉬운 안내 문구 노출(예: "약 드실 시간 알림은 끌 때까지 울려요. 보호자 알림 등은 강하게 울리지만 한 번씩 울려요.")
- **의료 안전 원칙**: "확실히 알림 받기(무음뚫기/강한 알림)"는 약 복용 안전과 직결 → **구독으로 막지 않고 가능한 무료/기본으로**. 구독은 **개인화(내 목소리·프리셋)** 중심.
- **강한 알림(무음뚫기/끝까지) 적용 범위**: **환자의 약 복용 관련만** — ① 약 먹을 시간 알림 ② 미복용 알림. 보호자가 받는 알림(예: "환자가 약 드셨어요")은 일반 알림. (단 알림음 꾸미기=녹음·프리셋은 보호자 알림에도 적용)
- **녹음 최대 길이**: **5초** (iOS 30초 제한 안전, "엄마~ 약 드세요~"에 충분).

### 프리셋 알림음 (가족 음성) — 방식 변경·보류 (2026-05-31)
- **효과음 프리셋 없음** (시스템 기본음과 차이 없어 의미 없음). 프리셋 = **"가족이 읽어주는 안내 음성"**만.
- ⛔ **Fish Audio TTS 방식 폐기 결정.** TTS는 생성할 때마다 **억양·타이밍·끝음 처리가 랜덤** → son_mom 한 판만 우연히 양호. 그 한 개를 살리려 수작업으로 쉼을 끼우고 끝음을 다듬었으나, **그 보정을 10개에 반복 = 비현실 + 결과물 들쭉날쭉**. "하나 세팅 후 목소리만 교체"는 TTS 특성상 불가. → **확장 불가로 판단, TTS 방식 전체 폐기.**
- ✅ **확정 방식: 사람이 직접 녹음한 10개.** 목소리 3종(어린이 1·성인남 1·성인여 1)이 멘트별로 읽음. 품질·일관성·쉼 모두 사람 녹음으로 한 번에 해결.

| 목소리 | 称호 멘트(파일) |
|---|---|
| 손주(어린이) | "할아버지 약 드세요" / "할머니 약 드세요" (2) |
| 성인 남성 | "아빠/아버지/엄마/어머니 약 드세요" (4) |
| 성인 여성 | "아빠/아버지/엄마/어머니 약 드세요" (4) |

- 성인 음성은 **친근(아빠/엄마) + 격식(아버지/어머니) 둘 다** 제공. 환자 성별도 둘 다. 멘트 = **"{호칭} 약 드세요" 확정**.
- ⏸ **녹음 주체 미정 → 프리셋 제작 보류.** (오너 가족·지인 직접 녹음 / 전문 성우 외주 중 추후 결정.)
- 🚀 **출시 우선순위 변경: 프리셋 없이 먼저 출시.** 핵심 차별점은 **"가족이 앱에서 직접 녹음 → 환자 알림음"** 이고, 이게 프리셋보다 중요. → **직접 녹음 기능을 먼저 완성·빌드.** 프리셋(사람 녹음 10개)은 녹음 주체 확정 후 번들 추가.
- `assets/sounds/presets/*.wav` (Fish Audio 생성본 10개)는 **폐기 대상**(참고용으로만 잔존, 출시 번들에 미포함).

### 구독 / 결제
- **모델**: **7일 무료 체험(기능 전부 사용 = 맛보기) → 구독해야 계속 사용**. 미구독 시 개인화 알림음 꺼지고 **기본 시스템 알림으로 복귀**(약 알림 자체는 계속 옴).
- **자동 전환**: 체험 시작 시 **결제수단 미리 등록 → 7일 후 자동 결제**("요즘 방식"). 
  - **법적 필수**: 한국 전자상거래법상 "○일 후 자동 결제" **명확 고지·동의 화면** 반드시 포함(다크패턴 규제·분쟁 방지).
- **가격**: **그룹 단위 월 990원 (해외 $0.99)**. 가족 그룹(patient_group) 하나당. 그룹 내 누가(주로 보호자) 결제하면 **그룹 전원 적용**.
- **결제 위치**: **웹**에서(앱스토어 수수료 회피). 앱은 entitlement만 반영.
- **체험 종료(미구독) 시 녹음 처리**: **보관**(서버) → 알림음만 기본 복귀, **재구독 시 녹음 복구**(재결제 유도+편의). 회원 탈퇴 시 삭제(보관기간·정책 명시 필요).
- **출시 순서**: **국내 먼저**(토스페이먼츠/카카오페이 등 국내 정기결제) → 해외(Stripe)는 나중에.
  - 참고: 한국은 법으로 앱 내 제3자 결제 허용. "웹 결제 → 앱 권한 반영" 방식 국내선 비교적 안전.
  - **국내 결제사(잠정): 토스페이먼츠** (정기결제/빌링 지원, 연동 깔끔). 구현 단계 최종 확정. 해외는 추후 Stripe.

### iOS 무음 뚫기 권한
- iOS 무음 뚫기 = **Apple `Critical Alerts` 특수 entitlement 필요** → 신청·승인(수 주, Apple 재량).
- 결정: **지금부터 미리 신청 준비·진행**(롱리드 항목이라 일찍). 의료(파킨슨 약 복용) 명분으로 소명.

## 2. 기술 메모 (구현 시 참고)

- **iOS 커스텀 알림음**: 앱 번들 또는 **`Library/Sounds`에 다운로드한 파일**만 가능. **30초 이내, caf/aiff/wav**(녹음 m4a → caf 변환). expo-notifications 기본으론 런타임 임의 사운드 불가 → **네이티브 모듈로 파일 쓰기+변환** 필요.
- **iOS 무음 뚫기**: Critical Alerts(entitlement) — 무음/DND 무시, 커스텀 사운드·볼륨 지정 가능. iOS 26+ `AlarmKit`은 예약 알람 대안(신버전 한정).
- **Android 커스텀 알림음**: notification channel에 사운드 지정(채널 불변 → 사운드 바뀌면 새 채널). 무음 뚫기는 **USAGE_ALARM** 사운드 + DND 우회. 알람시계형은 **전체화면 인텐트(FSI)+정확 알람** → Android 14+는 **"알람/전화 앱" 자격 + SCHEDULE_EXACT_ALARM/USE_FULL_SCREEN_INTENT 권한** 필요(약 알림 자격 가능). 배터리 최적화 예외 처리도.
- **푸시 발송**: 커스텀 사운드/critical는 Expo Push 지원 제한적일 수 있음 → 필요 시 **FCM/APNs 직접 발송** 고려.
- **예약 vs 교차**: 환자 약시간=기기 로컬 예약 알람이 가장 확실. 미복용·보호자=서버 푸시.
- **배포**: 전부 **네이티브 변경 → OTA 불가, 새 빌드 필요**. (현재는 출시 전이라 재심사 부담은 없음)
- **녹음 저장**: Cloudflare R2(기존 사용). 수신 기기가 다운로드 후 프로비저닝.
- **entitlement(구독 권한)**: 그룹 레벨로 DB 저장 → 멤버 앱이 그룹 구독 상태 확인 후 기능 잠금해제.
