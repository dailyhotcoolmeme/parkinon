# 파킨온 (ParkinON) 앱 설계 문서

---

## 1. 앱 개요

- **앱 이름**: 파킨온 (ParkinON)
- **타겟**: 파킨슨 환자 (60대 이상) + 보호자 (30대 이상)
- **핵심 가치**: 약 복용 관리, 약효 추적, 가족 연동, 파킨슨 정보 제공
- **플랫폼**: iOS + Android (React Native / Expo)

---

## 2. UI 원칙 (60대 이상 타겟)

- 글씨 최소 18sp 이상
- 버튼 최소 56dp 이상
- 한 화면에 정보 최대 2개
- 텍스트 입력 최소화 → 탭/선택 위주
- 고대비 색상
- 아이콘 + 텍스트 항상 함께
- 스와이프 제스처 최소화
- 작은 텍스트 링크 금지

---

## 3. 기술 스택

- **Frontend**: React Native / Expo (Managed Workflow)
- **Backend**: Supabase (Auth, DB, Realtime)
- **Storage**: Cloudflare R2 (영상/사진)
- **알림**: Expo Notifications
- **처방전 OCR**: Claude API Vision (Haiku 모델)
- **의약품 정보**: 식품의약품안전처 공공 API + 낱알식별 API
- **약 사진**: 식약처 알약 이미지 데이터 (미리 저장)
- **뉴스 크롤링**: GitHub Actions (주 2회)
- **로그인**: 카카오 OAuth (커스텀) + Google + Apple

---

## 4. 온보딩 슬라이드 (3장)

### 슬라이드 1
- **제목**: 약 먹는걸 잊지 않게 챙길 수 있어요.
- **설명**: 약 시간이 되면 알려드려요. 드셨으면 탭 한 번으로 끝이에요.

### 슬라이드 2
- **제목**: 가족들도 함께 알 수 있어서 더욱 안심이에요.
- **설명**: 약을 드시면 가족 모두가 알 수 있어요. 서로 확인하지 않아도 돼요.

### 슬라이드 3
- **제목**: 남긴 기록들은 다음 진료 때 참고할 수 있어요.
- **설명**: 약 먹은 후 몸 상태를 간단히 남겨두면 시간이 지나면서 변화가 보여요.

## 7. 가족 중 파킨온 사용자 확인 (환자/보호자 공통)


### "네, 있어요" 선택 시
```
가족에게 받은 초대 코드를 입력해주세요

[ ][ ][ ][ ][ ][ ]

[확인하기]

```

### "아니요/모르겠어요" 선택 시

```
괜찮아요.

[확인했어요]
```

## 8. 환자 온보딩 흐름

### 8-1. 기본 정보 입력 (4단계)

**화면 1** (4개 중 1번째)
```
이름이 어떻게 되세요?
[홍길동] ← 카카오 닉네임 자동 입력, 수정 가능
[다음으로]
```

**화면 2** (4개 중 2번째)
```
몇 년도에 태어나셨어요?
[선택해주세요 ▼]
[다음으로]
```

**화면 3** (4개 중 3번째)
```
성별이 어떻게 되세요?
[남자]  [여자]
```

**화면 4** (4개 중 마지막이에요)
```
파킨슨 진단은 언제 받으셨어요?
[선택해주세요 ▼]
나중에 설정에서 바꿀 수 있어요
[나중에 할게요]
[다음으로]
```

### 8-2. 약 등록

```
복용 중인 약을 등록할까요?
처방전 사진으로 한 번에 등록할 수 있어요.

[📷 지금 등록할게요]
[나중에 등록할게요]
나중에 설정에서 등록할 수 있어요
```

**"지금 등록할게요" 선택 시**
```
[📷 처방전 사진 찍기]
[✍️ 직접 입력할게요] ← 처방전 없는 경우
```

#### 처방전 사진 찍기
```
처방전을 찍어주세요
[📷 여기를 눌러서 사진을 찍어주세요]
갤러리에서 선택할 수도 있어요
```
→ 분석 중 로딩 → Claude API Vision 처리 → 확인 화면

#### 직접 입력
```
약 이름 선택 [드롭다운 ▼] ← 식약처 API 기반 파킨슨 약 목록
↓ 선택하면
[💊 약 사진]
용량 선택 [드롭다운 ▼] ← 해당 약 용량만 표시
하루에 몇 번? [1번] [2번] [3번] [4번]
복용 시간: [아침] [점심] [저녁] [취침]
← 각 시간대 탭하면 시간 선택 or 식사 후 바로 선택
[+ 약 추가하기]
[완료하기]
```

#### 약 확인 화면 (처방전 또는 직접 입력 후)
```
이렇게 드시는 게 맞나요?

아침 08:00
[💊 마도파] [💊 미라펙]

점심 13:00
[💊 마도파]

저녁 18:00
[💊 마도파] [💊 미라펙]

[네, 맞아요]
[수정할게요]
```

### 8-3. 알림 설정 (약효 추적)

```
약 복용 후 약효 지속 시간을
추적 관리할 수 있게 알림을 보내드려요.

아침 08:00
복용 후 30분 알림   🔵
복용 후 2시간 알림  🔵

점심 13:00
복용 후 30분 알림   🔵
복용 후 2시간 알림  🔵

저녁 18:00
복용 후 30분 알림   🔵
복용 후 2시간 알림  🔵

[확인했어요]
알림은 설정에서 언제든지 바꿀 수 있어요
```

※ 약 종류별 알림 기준:
- 레보도파 계열: 복용 후 30분, 2시간
- 도파민효현제: 복용 후 1시간
- MAO-B억제제: 별도 알림 없음 (레보도파 병용 시 레보도파 기준)
- 같은 시간대 복용 약 중 레보도파 있으면 레보도파 기준으로 통합

### 8-4. 가족 초대

```
가족을 초대할까요?
가족이 함께 보면 약을 더 잘 챙길 수 있어요.

[지금 초대할게요]
[나중에 할게요]
나중에 설정에서 초대할 수 있어요
```

**"지금 초대할게요" 선택 시**
```

카카오톡에서 초대할 가족을 선택하면 자동으로 전송돼요

[📤 카카오톡으로 보내기]
[나중에 할게요]
```

※ 카카오톡 메시지 내용:

## 10. 알림 체계

### 10-1. 약 복용 알림 흐름

```
복용 예정 시간 (예: 08:00)
↓
이미 복용 입력 완료 → 알림 없음
복용 입력 없음 → 첫 번째 알림
  "(파킨온) 아침 약 복용 시간이에요."
↓
+10분 복용 미입력
→ 두 번째 알림
  "(파킨온) 아직 아침 약을 드시지 않으셨어요."
↓
+10분 복용 미입력
→ 환자 알림
  "(파킨온) 아직 아침 약을 드시지 않으셨어요.
  보호자가 걱정하고 있어요."
→ 보호자 알림
  "(파킨온) OOO님께서 아직 아침 약을 드시지
  않으셨어요. 혹시 문제 없는지 확인해보세요."
```

### 10-2. 약효 추적 알림

- 복용 후 30분 알림 → 몸상태 탭으로 진입
- 복용 후 2시간 알림 → 몸상태 탭으로 진입
- 기본값 모두 ON / 사용자가 OFF 가능

**알림 설정 커스터마이징 가능**
- 시간 변경: 드롭다운 선택 (10분, 20분, 30분, 1시간, 2시간, 3시간 등)
- 알림 추가: 복용 시간대별로 알림 추가 가능
- 알림 삭제: 개별 알림 삭제 가능
- 복용 시간대별로 독립적으로 설정

```
아침 08:00 복용 기준
복용 후 30분   🔵  [시간 변경]  [삭제]
복용 후 2시간  🔵  [시간 변경]  [삭제]
+ 알림 추가

점심 13:00 복용 기준
복용 후 30분   🔵  [시간 변경]  [삭제]
복용 후 2시간  🔵  [시간 변경]  [삭제]
+ 알림 추가
```

### 10-3. 운동 알림

- 매일 사용자가 설정한 시간에 알림
- 기본값 OFF → 사용자가 시간 설정해야 ON
- 알림 문구: "(파킨온) 오늘 운동할 시간이에요."

### 10-4. 운동 팝업

- 약효 추적 상태 점수 4~5점 입력 시
- 알림 아닌 팝업으로 표시
```
몸 상태가 좋으시네요 😊
운동해보시겠어요?

[네, 해볼게요] → 운동 탭으로 이동
[괜찮아요]
```

### 10-5. 알림 설정 원칙

**기본값 모두 ON, 사용자가 직접 OFF 가능**
**단, 운동 알림은 기본 OFF → 시간 설정 시 ON**

**환자 알림**
```
약 복용 알림          🔵 기본 ON
약 복용 재알림        🔵 기본 ON
약 미복용 보호자 안내  🔵 기본 ON
약효 추적 알림        🔵 기본 ON
운동 알림             ⚪ 기본 OFF (시간 설정 시 ON)
```

**보호자 알림 (토글)**
```
약 복용했을 때        🔵 기본 ON
약효 상태 기록했을 때  🔵 기본 ON
운동 완료했을 때      🔵 기본 ON
약 미복용 알림        🔵 기본 ON
```

## 13. 몸상태 탭

### 13-1. 메인 화면

```
몸상태

2026년
3월 29일 (일)  📅

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

          ┌─────────────────────┐
          │  😊 몸상태 기록하기  │
          └─────────────────────┘

          🎬 영상 기록하기 →

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

- 📅 달력 버튼 탭: 날짜 선택 → 해당 날짜 기록 확인

### 13-2. 영상 기록하기 탭 시

## 18. 핵심 설계 원칙

### 약 복용 표시
- 환자/보호자 모두 시간대 기준 (아침/점심/저녁/취침)
- 약 이름은 보조 정보로 작게
- 약 이름 탭 → 식약처 API 팝업

### 증상 입력
- 절대값 아닌 점수 (1~5점)
- 이전 기록 언제 것인지 맥락과 함께 표시

### 가족 연동
- 초대 코드 방식 (딥링크 없음)
- 카카오톡으로 코드 전달
- 코드 유효시간 24시간
- 환자도 보호자 초대 가능, 보호자도 환자 초대 가능
- 각자 따로 가입한 경우 코드로 연동

### 영상/사진
- 무료: 30초 / 3개월 보관
- 저장: Cloudflare R2
- 경로: parkinon/videos/{patient_id}/{YYYY-MM}/
