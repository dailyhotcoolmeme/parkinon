# 복용 관리 통합 재설계 (슬롯 단일 소스 + 통합 등록 게이팅) — 스펙

상태: **구현·배포 완료** (2026-06-16) — A차 `d8340469`, B차 `3063f320`
관련: `MedicationManageScreen`, `DoseSlotSetList`/알림 설정, `MedicationRegisterScreen`(온보딩), `useDoseSlots`, `useMedication`, `medications`/`dose_slots`/`medication_dose_slots`, 와이어프레임 `docs/mockups/dose_manage_wireframe.html`

## 문제 (확정)
- "복용 시간"이 medications(meal_schedules)와 dose_slots 두 곳에 따로 저장. 실제 작동은 dose_slots만(알림·약효추적·홈·복용기록 전부 슬롯 기준, med_logs.medication_id 항상 null=슬롯단위 기록). 동기화는 약관리→슬롯 단방향뿐이라 **이미 어긋남**(마도파 약관리 8:00 vs 슬롯 8:30). 같은 시간을 두 곳에서 만져 혼란.

## 결정된 설계

### 1. 단일 소스 원칙
- **dose_slots = 시간·알림(약효추적)의 단일 소스.** medications는 시간 보유 안 함(meal_schedules는 source에서 격하/폐기, legacy 마이그레이션용으로만).
- medications = 약(이름·용량·item_seq·이미지·효능정보) + **어느 슬롯에 먹는지(medication_dose_slots M:N)**.

### 2. 통합 "복용 관리" 화면 (슬롯 중심, 한 곳)
- 슬롯(복용 시간대)마다: **① 시간 ② 알림/약효추적 설정 ③ 그 슬롯에 먹는 약 목록** 을 함께. [시간·알림 수정] / [약 넣기·빼기].
- "+ 복용 시간대 추가"(새 슬롯). "내 약 전체 보기"=약별 정보(효능·용법, 허가정보 연동)·이력.
- 기존 "알림 설정" 화면은 없애지 않되, 슬롯 시간·알림 관리를 이 통합 화면으로 흡수(메뉴 정리는 구현 시 결정).

### 3. 약 넣기/수정
- 약 추가: 처방전 OCR/검색(기존) → **시각 입력 없이 "어느 시간대(슬롯)에 먹는지" 체크** → 저장. 새 시간대 필요하면 슬롯 먼저 생성.
- 약 수정: 이름·용량·슬롯 배정 수정. **복용 시간 변경 = 슬롯의 시간 수정**(약 아님).

### 4. 약 변경 이력 — (가) 가벼운 방식
- `medications.ended_at`(이미 존재) 활용. 약 변경/중단 = 옛 약 ended_at 기록(비활성) + 새 약 추가. "중단한 약: 언제~언제 복용" 목록 보존. (날짜별 "그날 무슨 약" 스냅샷까지는 안 함.)

### 5. 온보딩 — 약 등록 제거
- **온보딩에서 약 등록 단계 완전 제거.** (가입 부담↓, 60대 타깃)
- 가입 완료 → **첫 로그인 화면에서 "통합 등록"(시간대 슬롯 + 약) 유도** 1회.
- **그룹 단위**: 환자 본인이 안 해도 **보호자가 그룹 대신** 통합 등록 가능. 그룹에 등록이 되어 있으면 완료로 간주.

### 6. 미등록 시 기록 차단 게이팅
- 첫 화면 유도를 무시하고 등록 안 한 경우 → **약복용·약효추적 기록을 누를 때 기록 못 남기게 막고, 통합 등록을 유도**.
- "등록 완료" 판정 기준(구현 시 확정): 그룹/환자에 활성 dose_slot 또는 약이 1개 이상 등록됐는지(또는 명시적 setup_done 플래그). 슬롯만 있고 약 없는 상태를 완료로 볼지 미정 → 확인 필요.

## 확정 (2026-06-15 최종)
- **온보딩: 약 + 시간대(슬롯) 둘 다 제거.** 온보딩=계정·역할·가족연동만. 시간대+약은 첫 로그인 "통합 등록"에서 한 흐름으로.
- **"등록 완료"(기록 차단 해제) 기준 = 활성 dose_slot(시간대)이 1개 이상.** 약은 없어도 기록 허용(약은 정보·이력용, 시간대가 알림·기록의 필수). 슬롯만 있고 약 없는 상태도 "완료"로 봄.
- 통합 등록은 시간대+약을 함께 유도하되, 게이트 해제는 시간대만으로 충분.

## 남은 확인 (구현 중)
- 기존 사용자(이미 약·슬롯 있음) 마이그레이션: meal_schedules→dose_slots 정합화, divergence(8:00/8:30) 정리.
- "알림 설정" 메뉴 존치/흡수(통합 화면으로 흡수 방향).
- 첫 로그인 "통합 등록" 화면 = 통합 복용 관리 화면을 setup 모드로 재사용할지, 별도 유도 화면일지.

## 구현 단계(안)
1. 데이터/판정: "그룹 등록 완료" 상태 정의 + 헬퍼. divergence 정리(슬롯을 정본으로).
2. 통합 "복용 관리" 화면(슬롯 중심: 시간·알림·약). 약 넣기=슬롯 체크.
3. 약 이력(ended_at, 중단 약 목록) + 내 약 전체 보기.
4. 온보딩에서 약(및 시간대) 등록 제거.
5. 첫 로그인 통합 등록 유도 + 기록 차단 게이팅.

각 단계는 별도 확인/배포.
