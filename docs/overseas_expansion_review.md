## 결정적 발견

1. **데이터는 서울에 둔 채로 다 된다.** 한국이 EU 적정성 결정국(2021.12)이라 GDPR상 EU→한국 이전이 SCC 없이 자유. 미·일도 소비자 건강앱에 현지 저장 의무 없음. → **인프라 이전 불필요.**

2. **최대 기술 벽 = 서버 알림이 한국시간(KST) 고정.** 해외 사용자는 약 알림이 엉뚱한 시각에 울림(환자 안전 직결). `users.timezone` 없음. **1순위 수정.** (단 약효추적 큐는 UTC 절대오프셋이라 안전)

3. **카카오 로그인·식약처 약검색은 벽이 낮다.** Apple/Google 로그인 이미 프로덕션 구현됨 → 해외는 카카오 버튼 로케일 게이트(OTA 가능). 약 등록은 수동 입력이 주 경로라 약DB 없이도 출시 가능. 파킨슨약은 전 세계 공통 성분(ATC N04)이라 나중에 RxNorm으로 쉽게 대체.

4. **광고+구독 수익모델은 3개 지역 다 가능.** (아래 별도 정리)

5. **차별점 분명.** 서양 PD 앱은 대부분 환자 단독형·iOS 편중. 파킨온의 **환자↔보호자 실시간 연동 + PD 전용 약효추적**이 빈 자리. 다만 순수 소비자 구독은 실패 이력 있어, 장기적으론 제약 B2B·독일 DiGA 급여 등 병행 검토.

## 수익화(광고 + 구독) — 정확한 사실

### 광고
- **핵심: 사용자의 건강 데이터(복약·증상·수면 등)를 광고 타게팅에 활용만 안 하면 자유롭게 붙일 수 있다.** ("건강데이터 광고 연결 금지"는 광고 자체 금지가 아니라 "건강데이터를 광고에 쓰는 것" 금지)
- 근거: Apple 가이드라인 **5.1.3(i)** (건강 맥락에서 수집된 데이터를 광고·마케팅에 사용 금지), **2.5.18** (건강/의료 데이터 기반 타게팅 광고 금지). Google Play·AdMob도 건강=민감데이터로 동일 제한.
  - 참고: 가이드라인에 "파킨슨"이란 단어는 없음. `MovementDisorder API`(Apple Watch 파킨슨 측정 API)는 명시돼 있으나 파킨온은 그 API를 안 쓰므로 일반 건강데이터 조항이 적용됨.
- **파킨온은 사실상 기본만 해도 준수됨**: 광고 SDK(AdMob 등)에 건강 데이터를 넘길 이유가 없음(배너/전면 광고만). `npa=1`(비개인화) 설정이면 끝. EU는 개인화 광고 시 CMP/동의 게이트 필요하나, 비개인화면 불필요.

### 구독 (핵심 주의)
- **구독 명분은 "광고 제거"가 아니라 "클라우드 저장(SaaS)"에 걸 것.** Apple은 "광고 제거"만으로는 자동갱신 구독을 거부함(지속가치 요건 미충족). "저장 용량 증가 + 보관 기간 연장"은 iCloud+/Google One처럼 자동갱신 구독으로 정당화되고, "광고 제거"는 부가 혜택으로 나열.
- 핵심 케어 기능은 **무료(광고 포함)로 유지**. 구독 필수 여부 공시.
- **구독 취소 시 이미 저장된 사진·영상 즉시 삭제 금지** → 유예기간 읽기전용(신규 업로드만 차단).
- 저장 확장 + 광고 제거를 **자동갱신 구독 하나로** 묶는 게 정답. (선택: 영구 광고제거를 별도 non-consumable로도 제공 가능)
- IAP 강제(디지털 구독). 수수료 Apple 15%(소규모 프로그램)/Google 구독 15%. ⚠️ Google이 2026-06-30부터 EEA/UK/US 요금 구조 변경 → 가격 책정 전 확인.

### 광고 SDK 도입 = OTA 불가
- `react-native-google-mobile-ads`는 네이티브 코드/manifest 추가 → **EAS Build 새 빌드 + 스토어 재심사 필수**(OTA 불가).
- iOS: ATT 프롬프트 + NSUserTrackingUsageDescription, SKAdNetworkItems, GADApplicationIdentifier. Android: AD_ID 권한 재도입(GMA SDK 자동 병합) + Play 광고ID 선언. iOS App Privacy / Play Data Safety 재선언.

## 지역별 규제 요약

| 항목 | 미국 | 일본 | EU |
|---|---|---|---|
| 개인정보 근거 | HIPAA 대개 비적용. FTC HBNR + CCPA/CPRA + 주별 건강법(WA MHMD 등) | APPI, 건강=요배려개인정보(옵트인 동의) | GDPR, 건강=특수범주(명시적 동의) |
| 데이터 국외이전(서울) | 제한 없음, 재이전(Anthropic) 고지 | 동의 + 이전국(한국) 정보 제공 | 적정성으로 SCC 불요 |
| 의료기기(SaMD) 위험 | 낮음(리마인더·기록=General Wellness) | 낮음(건강관리앱 비규제) | 낮음(단순 기록·저장은 MDSW 아님) |
| 난이도 | 진입 용이~보통 | 보통 | 까다로움 |

- **SaMD 경계**: 증상/영상/음성 자동 분석으로 "악화/약효저하 판정", "약 용량 변경 제안", AI 진단 스코어 등을 넣으면 의료기기 규제 대상化 위험. 현재의 "자가 기록·면책 명시" 포지션 유지하는 한 세 지역 다 리스크 낮음.
- **미국 최대 리스크**: 광고/분석 SDK를 통한 건강데이터 유출(FTC HBNR은 무단 공유도 "침해"로 봄). → 건강데이터와 광고 SDK 코드 분리로 해소.
- **EU 추가 의무**: 명시적 동의 UI, EU 대리인(제27조), 규모 성장 시 DPO·DPIA, 72h 침해통지. 커뮤니티(UGC) 있으면 DSA 최소 의무(신고 메커니즘 16조·조치사유 통지 17조·약관 14조·연락창구). 소규모는 투명성 보고서 등 면제.
- **세금**: 표준 IAP는 Apple/Google이 판매자로 소비세(EU VAT·미국 판매세·일본 소비세 10%) 대행. 개발자는 소득세·세금서식(W-8BEN 등)만.

## 약DB 현지화 전략 (핵심 지렛대)
각국 전체 약DB를 좇지 말고, **파킨슨약(레보도파·카비도파·로피니롤·프라미펙솔·라사길린·엔타카폰·아만타딘 등, 전부 ATC N04) 수십 종만** 캐노니컬 마스터 테이블로 구축 → 각국 로컬코드(미 NDC/RxNorm, 영 dm+d, 프 CIS-BDPM, 일 YJ)를 매핑. 범위가 수십 배 축소됨. 낱알식별은 어느 나라든 무료 공공 API 없음 → PD약 한정 자체 이미지 세트가 현실적.

## 확정된 방향 (2026-07-02 오너 결정)

- **1차 = 영어권 동시 출시** (미국·영국·캐나다·호주·아일랜드·뉴질랜드). 영어 앱 하나 + 스토어 배포국가 다중 선택. EU(독/프)는 DSA·GDPR 추가 작업 있어 2차로 분리.
- **1차부터 수익화 = C안(구독 + 광고)**. 다운로드는 무료.
  - 이유: 구독의 강력한 전환 유인이 "광고 제거"이므로, 광고 없이 구독만(B)이면 명분이 약함. 또 B든 C든 어차피 네이티브 재빌드가 필요 → 재빌드 한 번에 광고까지 넣는 게 효율적.
  - **구독 심사 뼈대 = "클라우드 저장(SaaS, 저장용량+보관기간)"**, 마케팅 전면 = "광고 제거 + 저장 확장" 둘 다. (광고 제거만으론 자동갱신 구독 심사 거부되므로 저장을 뼈대로)
  - **광고 배치는 화면 배제 없음(2026-07-04 정정 — 해외는 수익화 우선)**: 배너 전용·화면당 1개·핵심 조작 버튼과 분리된 고정 위치로 오터치만 방지. 상세는 `overseas_execution_plan.md` Phase 5.5, `docs/monetization_plan.md` 참고.
  - 광고는 비개인화(npa=1), 건강데이터 광고 SDK 전달 금지.
- **시간 현지화 = 사용자별 타임존 자동 감지·저장 기능**으로 해결 → 미국 내 시차 포함 전 세계 자동 커버. (한 번 제대로 만들면 나라별 시차 이슈 없음)
- **나라별 차이 = 언어 번역 + 법률(약관/동의)만.** 영어권은 대체로 공통 커버.
- **운동영상**: 나중에 보완 or 제외. **약검색**: 없어도 됨(숨김). **OCR**: 해외 처방전 지원되면 나중에.

### 수익화에 따른 사업자 세팅 (필수)
구독 판매 시 개발자 계정에 판매자 세팅 추가 필요:
- Apple: 유료 앱 계약(Paid Apps Agreement) + 은행 계좌 + 세금 서식(비미국=W-8BEN)
- Google: 결제 프로필 + 은행 + 세금 정보
- 매출은 한국에서 소득 신고(아워마인 사업자/법인). 부가세·현지 소비세는 스토어(MoR)가 대행.

## 로드맵
1단계: 영어권 MVP → **미국·영국·캐나다·호주 등 동시 출시**. 다운로드 무료 + 구독 + 광고(C안). 재빌드·재심사 1회.
  - 선결: 타임존 자동화(환자안전 최우선), i18n+영어, 카카오 게이트, 약검색 숨김, 약관/동의 영어화, IAP 구독(RevenueCat 등)+저장 티어, 광고 SDK.
2단계: 일본어 → 일본
3단계: 독일/EU(GDPR·DSA·DiGA 급여, 규제 투자 큼)
