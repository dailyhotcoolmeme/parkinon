# 알림 설정 액션 결과 안내 팝업 (상황 인지형) — 스펙

상태: **구현 진행** (2026-06-13 결정, 상황확인 맞춤문구 채택)
관련: `src/components/settings/DoseSlotSetList.tsx`, `src/screens/menu/SettingsScreen.tsx`, `src/context/SettingsContext.tsx`, 발송 함수들.

## 목적
알림 설정에서 액션(시간조정/on·off/삭제)을 할 때마다, **그 변경이 언제 적용되는지 정확히** 팝업으로 안내해 사용자 오해 방지. 문구는 **실제 상태를 확인해 맞춤**으로 바뀜.

## 확정된 실제 동작 (근거: 코드/DB 조사)
- **약 복용 / 운동 / 약 미복용**: 서버 크론이 매 1분 DB를 라이브로 읽어 발송 → **즉시 적용**. 단 "오늘 그 시각이 이미 지났으면 오늘은 안 오고 내일부터".
- **약효추적**: 약 복용 순간 `effect_tracking_queue`에 그날 알림이 **예약 박제**됨 → **지연**. 오늘 이미 복용했으면 오늘 약효알림은 복용 시점 기준대로 오고(설정변경으로 못 지움), 바꾼 내용은 **다음 복용부터**. 복용 전 변경은 그 복용부터 적용.

## 문구 로직 (상황 인지형)
공통: 액션 성공 후 결과 팝업(앱 기존 `dialog.alert({title, message})` 사용). 제목 짧게, 본문 표준·일반어(애기말투 금지).

### 약 복용 알림 (DoseSlotSetList 슬롯 단위)
- **시간 변경**(remind 켜진 슬롯): KST 현재시각 대비 새 시각 비교.
  - 아직 안 지남 → "바로 적용됐어요. 오늘 {HH:MM}부터 알려드려요."
  - 이미 지남 → "바로 적용됐어요. 오늘 {HH:MM}은 지나서, 내일부터 이 시간에 알려드려요."
  - (remind 꺼진 슬롯의 시간만 변경) → "시간을 바꿨어요. 이 약 복용 알림은 꺼져 있어요."
- **켜기**: 안지남 → "알림을 켰어요. 오늘 {HH:MM}부터 와요." / 지남 → "알림을 켰어요. 오늘은 지나서 내일부터 와요."
- **끄기**: "알림을 껐어요. 지금부터 이 시간 알림은 오지 않아요."
- **삭제**: "이 복용 시간을 삭제했어요. 지금부터 알림이 오지 않아요."

### 약효추적 알림 (DoseSlotSetList 슬롯 단위: 간격변경/track on·off/슬롯삭제)
- 상황확인: **오늘(KST) 그 슬롯 약을 이미 복용했는지** = `med_logs`에서 patient_id+dose_slot_id+taken_at(오늘) 존재 여부 조회.
- 이미 복용 → "오늘 이 약은 이미 드셔서, 오늘 약효추적 알림은 기존 설정대로 와요. 바꾼 내용은 다음에 약을 드실 때부터 적용돼요." (track off/슬롯삭제도 동일 + "이미 예약된 오늘 알림은 올 수 있어요.")
- 아직 안 복용 → "바꾼 내용은 다음에 이 약을 드실 때부터 적용돼요. 오늘 복용분부터 반영돼요."

### 운동 알림 (exercise_notif_prefs: 시간/on·off/삭제)
- 약 복용과 동일 패턴(시간 비교: 안지남→오늘부터 / 지남→내일부터, 끄기·삭제→즉시 중단).

### 약 미복용 알림 (med_time_notif_prefs.missed_first/second 토글)
- 켜기 → "켰어요. 바로 적용돼요. 미복용 알림은 약 복용 시각 10분·20분 후에 와요."
- 끄기 → "껐어요. 지금부터 미복용 알림은 오지 않아요."

## 구현 메모
- "오늘 지났는지": KST 기준 슬롯 time(HH:MM) vs 현재. (앱의 KST 처리 방식 재사용)
- "오늘 복용했는지": med_logs 조회(SECURITY/ RLS 통과하는 기존 supabase 클라이언트). DoseSlotSetList가 patientId 접근 가능.
- 이관/미이관: 약 복용 on/off는 이관환자=dose_slots.remind_enabled(DoseSlotSetList 토글)에 팝업 연결이 안전. 미복용 토글은 양쪽 공통.
- 팝업은 액션 **성공 후**에만. 실패 시 기존 에러 처리 유지. 너무 시끄럽지 않게 간결히.
